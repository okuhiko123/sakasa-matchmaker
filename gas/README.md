# 回答の記録をはじめる（10分ほど）

占いの結果をスプレッドシートに貯めて、管理画面で集計を見るための手順です。
設定するまでは、どこにも送らずに動きます（占い自体はいま普通に使えます）。

## 1. スプレッドシートを作る

Googleドライブで新しいスプレッドシートを作り、名前をつけます。
たとえば「さかさマッチメーカー 回答ログ」。

## 2. スクリプトを貼る

そのスプレッドシートで **拡張機能 → Apps Script** を開きます。
最初から入っている `function myFunction() {}` を全部消して、
このフォルダの [`Code.gs`](Code.gs) の中身をまるごと貼り付けます。

貼ったら、いちばん上のほうにある

```js
var ADMIN_KEY = 'change-me';
```

の `change-me` を、**好きな合言葉**に変えてください。管理画面を開くときに使います。
（人に教えなければ、他の人は集計を見られません）

保存します。

## 3. ウェブアプリとして公開する

右上の **デプロイ → 新しいデプロイ**。

- 種類を選択（歯車マーク）→ **ウェブアプリ**
- 次のユーザーとして実行 → **自分**
- アクセスできるユーザー → **全員**

「デプロイ」を押すと、1度だけ Google の許可画面が出ます。
「詳細」→「（プロジェクト名）に移動」→「許可」と進んでください。
自分のスプレッドシートに書き込むための許可です。

最後に出てくる **ウェブアプリのURL** をコピーします。
`https://script.google.com/macros/s/……/exec` という形です。

## 4. アプリにURLを教える

`config.js` を開いて、コピーしたURLを貼ります。

```js
window.SM_CONFIG = {
  logEndpoint: 'https://script.google.com/macros/s/……/exec'
};
```

保存して、push すれば1〜2分で反映されます。

```bash
git add -A && git commit -m "記録先を設定" && git push
```

## 5. 集計を見る

`admin.html` を開きます。

**https://okuhiko123.github.io/sakasa-matchmaker/admin.html**

ウェブアプリのURLと、2で決めた合言葉を入れると集計が出ます。
このページは占いの画面からはリンクしていないので、URLを知っている人しか辿り着けません。
さらに合言葉が合わないとデータが返ってこないので、URLが漏れても中身は見られません。

---

## 記録されるもの・されないもの

| 記録する | 記録しない |
|---|---|
| ニックネーム（任意・自由入力） | 氏名・住所・電話番号・メールアドレス |
| 都道府県と市町村 | それより細かい所在地 |
| 9つの質問の答え | IPアドレス |
| 結果に出た掲載者と相性％ | 端末の識別子・Cookie・閲覧履歴 |
| 日時、スマホ／パソコンの別 | ブラウザの詳細情報 |

ニックネームは自由入力なので、万が一メールアドレスや電話番号が書かれた場合に備えて、
**アプリ側とGAS側の両方で、送信前に自動で取り除く**ようにしてあります。

## あとから変えたいとき

- **合言葉を変える**：`Code.gs` の `ADMIN_KEY` を書き換えて、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**。URLは変わりません。
- **記録をやめる**：`config.js` の `logEndpoint` を空にして push。
- **記録を消す**：スプレッドシートの行を消すだけです。
