**設定は済んでいます。** 何もしなくても記録は動いています。

## 集計を見る

**https://okuhiko123.github.io/sakasa-matchmaker/admin.html**

URLは自動で入るので、**合言葉だけ**入れれば集計が出ます。

このページは占いの画面からリンクしていないので、URLを知っている人しか辿り着けません。
さらに合言葉はGAS側で照合していて、合わないとデータそのものが返ってきません。
**URLが漏れても中身は見られない**ということです。

生の行をそのまま見たいときは、スプレッドシートの `log` シートを開いてください。

## 記録されるもの・されないもの

| 記録する | 記録しない |
|---|---|
| ニックネーム（任意・自由入力） | 氏名・住所・電話番号・メールアドレス |
| 都道府県と市町村 | それより細かい所在地 |
| 9つの質問の答え | IPアドレス |
| 結果に出た掲載者と相性％ | 端末の識別子・Cookie・閲覧履歴 |
| 日時、スマホ／パソコンの別 | ブラウザの詳細情報 |

ニックネームは自由入力なので、万が一メールアドレスや電話番号が書かれた場合に備えて、
**アプリ側（`app.js` の `cleanNick()`）とGAS側（`Code.gs` の `scrub_()`）の両方で、
保存される前に自動で取り除く**ようにしてあります。

送る内容を変えるときは、`index.html` の利用規約（第3条）も合わせて直してください。

## あとから変えたいとき

- **合言葉を変える・増やす**：Apps Script で `ADMIN_KEYS` の配列を書き換えて、
  **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**。
  URLは変わりません。`_secret/admin-key.txt` も書き換えておくこと。
- **記録をやめる**：`config.js` の `logEndpoint` を空にして push。
- **記録を消す**：スプレッドシートの行を消すだけです。

## ゼロから作り直すとき

1. スプレッドシートを作る
2. **拡張機能 → Apps Script** を開き、[`Code.gs`](Code.gs) の中身をまるごと貼る
3. `ADMIN_KEYS` に好きな合言葉を入れて保存（いくつ並べてもよい）
4. **デプロイ → 新しいデプロイ** → 種類（歯車）→ **ウェブアプリ** →
   実行するユーザー **自分** / アクセスできるユーザー **全員**
5. 1度だけ許可画面が出る（「詳細」→「〜に移動」→「許可」）
6. 出てきた `https://script.google.com/macros/s/……/exec` を `config.js` に貼って push
